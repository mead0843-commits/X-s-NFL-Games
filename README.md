# X's NFL Games

A local-first football game hub with:
- 20-0 challenge mode
- trivia mode
- guess-the-player mode
- local 2-player couch duel
- ultimate team card collection
- infinite season pass progression
- coin-based economy and profile upgrades

## Run it locally

Open `index.html` in a browser.

You can also serve it with a tiny local server, for example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project structure

- `index.html` — app shell and screens
- `styles.css` — premium sports UI styling
- `script.js` — game logic, state, and mode behavior

## Notes

This is a functional prototype built for a same-device local experience without online multiplayer.
It focuses on the game concept and progression loop rather than a production backend.
